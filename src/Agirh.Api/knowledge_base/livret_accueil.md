# Livret d'Accueil AGIRH

## Congés et Absences
- Tout employé AGIRH commence avec **25 jours de congés payés** par an.
- Le **Compte Épargne Temps (CET)** permet de capitaliser jusqu'à **10 jours** non pris.
- Les **congés sans solde** sont possibles après accord du manager.
- Les **arrêts maladie** doivent être déclarés dans les 48h.

## Télétravail
- Le **télétravail** est autorisé jusqu'à 3 jours par semaine.
- Une **demande formelle** doit être soumise via le portail RH.

## Primes
- **Prime annuelle** : versée en décembre, calculée sur objectifs.
- **Ticket restaurant** : 10 €/jour travaillé (60% employeur, 40% employé).
- **Mutuelle** : prise en charge à 50% par l'employeur.
