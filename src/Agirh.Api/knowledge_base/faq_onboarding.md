# FAQ Onboarding AGIRH

## Comment consulter mon solde de congés ?
Ouvrez votre navigateur, connectez-vous au portail RH Agirh (https://rh.agirh.fr), puis cliquez sur l'onglet "Mes Congés". Le solde apparaît en haut à droite.

## Comment poser une demande de congés ?
Dans le portail RH, cliquez sur "Nouvelle demande", sélectionnez les dates, ajoutez un motif facultatif, puis validez. Votre manager reçoit une notification.

## Qui contacter pour un problème technique ?
Contactez le support IT à l'adresse support@agirh.fr ou via le tél. 01 23 45 67 89 (poste 456).

## Comment sont calculés les RTT ?
Les RTT sont calculés au prorata du temps de travail. Pour un temps plein, 12 jours de RTT par an sont accordés.

## Puis-je reporter mes congés sur l'année suivante ?
Oui, avec l'accord de votre manager, vous pouvez reporter jusqu'à 5 jours sur l'année N+1. Au-delà, ils sont perdus sauf accord exceptionnel de la DRH.
